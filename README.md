# Luna Genjutsu

Бесплатный аналог Higgsfield Genjutsu для своего компьютера. Вы загружаете видео-референс, фото лица и фото в полный рост и нажимаете «Сгенерировать». В готовом видео будете вы, а движения, камера, фон и **оригинальный звук** останутся как в исходнике. Всё остальное приложение делает в фоне.

Само приложение бесплатное и работает локально. Платите вы только за генерацию в Seedance своим ключом, а за маску SAM 3 платите, только если включите её: это несколько центов на Replicate.

## Как это работает

```
видео ──► 24 fps, ≤960 px ──► человек скрыт силуэтом ──► + голос (+3 полутона) ──┐
фото лица + в полный рост ────────────────────────────────────────────────────────┼─► Seedance ──► + оригинальный звук ──► результат
```

1. **Скрываем человека в исходнике.** Он заменяется цветным силуэтом-картой глубины на оригинальном фоне. Seedance видит только движение, а не чужое лицо. Это решает проблему, из-за которой Seedance отклоняет видео с реальными людьми.
   - **Облако** (`REPLICATE_API_TOKEN`): маски SAM 3 и карта глубины Video Depth Anything. Даёт лучшее качество, как в [Genjustsu Open Source Workflow](https://github.com/sirioberati/Genjustsu-Open-Source-Workflow).
   - **Локально** (бесплатно, ничего не уходит из компьютера): MediaPipe выделяет человека и рисует скелет позы, чтобы руки на фоне тела не терялись. Трекер держится за одного человека и не перескакивает на соседа, если детектор на мгновение его потерял.
   - Маска чистится автоматически: убираются обрывки, заполняются дыры, мерцание подавляется голосованием по соседним кадрам, силуэт расширяется, чтобы скрыть волосы и края одежды.
2. **Проверяем маску автоматически.** Если человек не найден на части кадров, маска мерцает или закрывает пол-экрана, задача останавливается и показывает превью: подтвердите или отмените. Если всё в порядке, отправка идёт сама.
3. **Липсинк.** Голос отделяется от музыки (Demucs) и сдвигается на +3 полутона, чтобы модель не получила голос исходного человека. Он встраивается в видео-гид, чтобы губы попадали в речь.
4. **Промпт собирается сам.** Порядок такой: что сохранить (движение, камера, тайминг) → кого заменить → чьи фото (полный рост, лицо) → чего не делать. Основа — промпт из карточки MiniMax H3 Character Swap LoRA ([workflow frizzy](https://github.com/Thefrizzy1/The_frizzy1-Workflows/tree/main/workflows/minimax/h3-character-swap-12gb)).
5. **Генерация.** Сначала черновик, потом по кнопке 1080p. Клипы длиннее лимита провайдера режутся на части и склеиваются, клипы короче 4 с дополняются и обрезаются обратно.
6. **Возвращаем оригинальный звук целиком.** Он копируется байт в байт. Картинка не растягивается, поэтому речь и биты остаются на своих местах.

Платный запрос никогда не отправляется повторно сам. После перезапуска приложение только продолжает опрашивать уже отправленные задачи.

## Установка

Нужны Python 3.10+ и ffmpeg (`brew install ffmpeg` или `sudo apt install ffmpeg`).

```bash
git clone https://github.com/orcspace/Luna-Genjutsu-.git
cd Luna-Genjutsu-
./setup.sh      # Windows: start.bat
./start.sh      # откроется http://127.0.0.1:8770
```

Ключи вставьте в **Настройки** прямо в интерфейсе. Они сохраняются только в локальном `.env`.

| Ключ | Зачем |
|---|---|
| `ENHANCOR_API_KEY` | Seedance через [Enhancor](https://app.enhancor.ai/api-dashboard): разрешает ваше лицо на референсах (`pass_faces`), черновик → 1080p. **Рекомендуется.** |
| `BYTEPLUS_API_KEY` | Официальный BytePlus ModelArk. Seedance 2.x там отклоняет реальные лица на фото, если они не загружены в вашу приватную библиотеку портретов. |
| `REPLICATE_API_TOKEN` | Необязательно. Облачная маска SAM 3 + глубина и отделение голоса Demucs. Без него маска делается локально, а для липсинка используется весь звук. |

Чтобы проверить всё без оплаты, выберите провайдера **«Тест без оплаты (mock)»**. Он пройдёт весь путь и вернёт перекрашенный видео-гид.

Чтобы работал локальный режим на Linux без графики, поставьте `sudo apt install libegl1 libgles2`.

## Как Seedance получает файлы

По умолчанию поднимается временный туннель Cloudflare (`cloudflared` скачается сам) к **отдельному** порту. Этот порт отдаёт только файлы текущих задач по случайным ссылкам и принимает webhook. Интерфейс наружу не открывается. Вместо туннеля можно выбрать в настройках `tmpfiles` или `litterbox` (публичные временные ссылки) либо указать свой адрес в `PUBLIC_BASE_URL`.

## Советы для лучшего результата

- В видео один человек, без жёстких склеек, длина 4–15 с. Склейки и сплит-экран сбивают трекинг.
- Фото лица: анфас, ровный свет, без очков. Фото в полный рост: с головы до ног, в нужной одежде. Дополнительные ракурсы (сбоку, сзади) помогают.
- Если людей несколько, напишите в «Кого заменить» по-английски, например `man in the black jacket`. Это понимает облачная маска SAM 3, а локальная берёт самого крупного человека.
- Меняйте одну вещь за раз: сначала человека, потом одежду в «Дополнительно».

## Разработка

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Структура: `genjutsu/jobs.py` — конвейер и состояние задач, `masking.py` — маски и видео-гид, `audio.py` — голос, `providers.py` — Enhancor / BytePlus / mock, `prompts.py` — промпт, `hosting.py` — туннель и файлы, `server.py` — API, `static/` — интерфейс.

Используйте только своё лицо или лица людей, которые дали согласие.
